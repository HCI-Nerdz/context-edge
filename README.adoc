== About The Project

Cloud consoles and suite entrypoints often *overload* the entrypoint header with subsection platforms.
*Context rails* put ecosystem nav on the top and/or left edges: hover expands the rail; click opens a wireframe platform map; each subplatform keeps a stable color overlay.

Streets under skyscrapers — not streets painted on the roof.

Part of link:https://github.com/HCI-Nerdz[HCI Nerdz].

* Essay: link:https://hci-nerdz.github.io/blog/when-platforms-overload-the-entrypoint/[When platforms overload the entrypoint]
* Org site desk: link:https://hci-nerdz.github.io/demos/context-rails/[vanilla desk]

=== Demos

[cols="1,2"]
|===
| Route | Island / aesthetic

| `/demos/solid-cloud/`
| Solid — Map Edge · cloud-console parody + overload toggle

| `/demos/react-suite/`
| React — Map Edge · suite shell, duo-tone overlays (Next-portable)

| `/demos/svelte-community/`
| Svelte — Map Edge · community/spaces chrome

| `/demos/vanilla-mature/`
| Vanilla — Map Edge · color-only mature rails

| `/demos/modal-edge/`
| Vanilla — *Modal Edge* · View Transitions ancestry stack (Variant B)

| `/demos/path-edge/`
| Vanilla — *Path Edge* · breadcrumb color series (Variant C)
|===

Shared contracts: `src/lib/platforms.ts` (Map Edge), `src/lib/nav-stack.ts` (Modal Edge).

Two click models (do not force into one gesture while studying):

* *Map Edge* — edge opens a wireframe / directory of destinations
* *Modal Edge* — edge is the current node; click slides the sheet to reveal colored ancestor layers
* *Path Edge* — rail is the breadcrumb (unique color sequence); paired hover; labels on top; one mark per level, current at top-left
+
Also called Nav Edge / Context Edge in conversation.

pnpm install
pnpm dev
----

Build for GitHub Pages (`base: /context-rails/`):

[source,bash]

== Framework impedance

Context rails are long-lived *shell chrome* (hover width, open overlay, platform identity).

[cols="1,2"]
|===
| Host | Notes

| Solid + SolidStart
| *Shines.* Reuse `src/components/solid/ContextRailsShell.tsx` in a SolidStart root/layout. This repo does not ship a SolidStart app — SolidStart is the natural production host, not a demo requirement.

| React + Next.js
| *Valuable.* Port `src/components/react/ContextRailsShell.tsx` as a `"use client"` layout wrapper. Keep live overlay identity in client state across the RSC boundary.

| Svelte + SvelteKit
| *Strong for motion.* Kit layout slots mirror the substrate idea.

| Astro islands
| *Excellent for demos.* If each platform is already a heavy SPA, put rails inside that SPA shell.

| Vue / Nuxt
| Fine; not prioritized once Solid + React + Svelte exist.

| Mobile-first
| Edge hover is a poor default — out of scope for this MVP.
|===

Full write-up: link:https://hci-nerdz.github.io/docs/hci-nerdz/context-rails.html[Context rails docs].
